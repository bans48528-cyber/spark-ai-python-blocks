# Reverse Compiler Notes

`sparkai_reverse.py` is the core Python-to-block compiler.

It accepts the Python dialect generated by Spark AI, not arbitrary Python. The
goal is to reproduce the same graphical blocks a user could build in the Spark
AI UI.

## Output Modes

- `.sparkai`: `compile_project()` reads `templates/base.sparkai`, replaces the
  sprite block graph and writes variables/lists into stage metadata.
- Clipboard XML: `sparkai_clipboard.compile_clipboard()` serializes the same
  block graph into XML fragments that can be pasted into Spark AI.

## Mapping Comments

Variables and lists:

```python
# @sparkai-variable ShiJian_ => 时间
# @sparkai-list SuDu_ => 速度
# @var Power_=最大功率
# @list Speeds_=速度列表
```

Custom blocks:

```python
# @sparkai-custom drive => 驱动 功率 %n 执行 %b
# @sparkai-custom-arg drive Power_ => 功率
# @sparkai-custom-arg drive Enabled_ => 执行
```

## Error Policy

Unsupported functions, unknown variables/lists and impossible UI shapes raise
`ReverseCodeError`. This is intentional. The generator should fail loudly when
it cannot prove that the output corresponds to a real Spark AI block.

## Adding Blocks

Add support in small steps:

1. Capture a real Spark AI sample.
2. Identify opcode, fields, inputs and shadow types.
3. Implement the compiler branch.
4. Add shape validation if the UI slot type is special.
5. Add regression tests.
